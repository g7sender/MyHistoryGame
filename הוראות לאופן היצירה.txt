שילוב של לוח משימות יחד עם סיפור רקע מקדים הוא בדיוק מה שיהפוך את המשחק למשהו שכיף לצרוך כידע כללי ולא סתם עוד בוחן יבש. הסיפורים הקצרים נותנים את ה"וייב" וההקשר ההיסטורי, והבחירה החופשית בלוח המשימות נותנת שליטה מלאה לשחקן.
ארגנתי עבורך את תוכנית הארכיטקטורה והעבודה שאפשר לתת ל-Claude Code כדי להרים את הפרויקט בצורה חלקה.
תוכנית אדריכלית למשחק (מוכן ל-Claude Code)
1. מבנה הנתונים (Data Structure - JSON)
הכי נוח לבנות את כל תוכן המשחק בקובץ JSON מרכזי. כך Claude Code יוכל לייצר לך בקלות עוד ועוד תוכן. מבנה לדוגמה:
{
  "worlds": [
    {
      "id": "greece",
      "name": "יוון העתיקה",
      "theme": "greek-marble", // יגדיר את העיצוב/צבעים לעולם הזה
      "description": "עידן של פילוסופים, אלים אדירים, קרבות מיתולוגיים והולדת הדמוקרטיה.",
      "missions": [
        {
          "id": "greece_1",
          "title": "הקרב בתרמופילאי",
          "story": "שנת 480 לפנה''ס. צבא הפרסי העצום של חշאירש (חเสרקס) צועד לעבר יוון. 300 לוחמים ספרטנים בפיקודו של המלך ליאונידס עומדים בפרץ במעבר ההר הצר...",
          "question": "מי הוביל את 300 הלוחמים הספרטנים בקרב בתרמופילאי?",
          "options": ["אכילס", "ליאונידס", "אלכסנדר הגדול", "אודיסאוס"],
          "answer": 1
        }
      ]
    }
  ]
}

2. זרימת המסכים (Screen Flow)
 * מסך ראשי (Dashboard / World Map): מציג את לוח המשימות/העולמות (יוון, רומא, ימי הביניים, גילוי אמריקה) עם חיווי על התקדמות (למשל, אחוז השלמה לכל עולם).
 * מסך סיפור (Story Intro): כשלוחצים על משימה, נפתח מסך ביניים מעוצב עם הסיפור הקצר והאנקדוטה על אותו אירוע, ומשם כפתור "התחל אתגר".
 * מסך אתגר (Quiz / Challenge): השאלות עצמן, עם פידבק מיידי (תשובה נכון/שגוי) והסבר קצר נוסף שמסביר למה זו התשובה הנכונה (להעשרת הידע).
3. עיצוב לפי עולמות (Theming)
כדי שכל עולם ירגיש שונה, אפשר להשתמש במשתני CSS (או ב-Tailwind) שמשנים את פלטת הצבעים והפונטים לפי העולם הנבחר:
 * יוון העתיקה: גווני שיש, זהב וכחול ים-תיכוני.
 * האימפריה הרומית: אדום ארגמן, זהב ואבן עתיקה.
 * ימי הביניים: גווני חום עמוק, פלדה וירוק כהה (אווירת טירות).
 * גילוי אמריקה: גווני קלף ישן, עץ חם וירוק של ג'ונגל/ים.
איך לגשת לזה מול Claude Code?
אתה יכול לפתוח חלון עבודה עם Claude Code ולתת לו את הנחה הבאה (Prompt) שתתן לו את כל ההקשר:
> "אני רוצה לבנות אפליקציית ווב (Web App) למשחק היסטוריה לימודי. האפליקציה צריכה לכלול מסך ראשי שבו בוחרים עולמות היסטוריים (יוון העתיקה, האימפריה הרומית, ימי הביניים, גילוי אמריקה) דרך לוח משימות. לכל משימה יהיה סיפור קצר ברקע להעשרת הידע, ולאחר מכן שאלת אתגר/טריוויה עם הסבר על התשובה. העיצוב צריך להשתנות בהתאם לעולם הנבחר. בוא נתחיל ביצירת מבנה בסיסי (רצוי ב-React + Tailwind או Vanilla JS מודרני לבחירתך) עם קובץ JSON שמרכז את התוכן."
