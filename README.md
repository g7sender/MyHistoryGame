# מסע בזמן - משחק היסטוריה לנייד

משחק ווב לימודי בהיסטוריה, בנוי ב-React + Tailwind CSS + Vite, מותאם לשימוש בטלפון.

## הרצה מקומית

```bash
npm install
npm run dev
```

ואז לפתוח את הכתובת שמודפסת בטרמינל (בד"כ `http://localhost:5173`). כדי לבדוק תצוגת מובייל - לפתוח את כלי הפיתוח של הדפדפן (F12) ולהפעיל את "device toolbar".

## בנייה לפרודקשן

```bash
npm run build
```

התוצר ייכנס לתיקיית `dist/`, מוכן להעלאה לכל שירות אחסון סטטי (GitHub Pages, Vercel, Netlify וכו').

## הוספת תוכן (עולמות ומשימות)

כל התוכן של המשחק חי בקובץ [`src/data/worlds.js`](src/data/worlds.js) - אין צורך לגעת ברכיבים כדי להוסיף עולם או משימה חדשה. כל עולם הוא אובייקט עם `id`, `order` (סדר כרונולוגי), `name`, `subtitle`, `whyItMatters`, `theme` (צבעי `primary`/`secondary`/`accent`) ומערך `missions`. כל משימה כוללת `story.text` (הסיפור הקצר) ו-`challenge` (שאלה, 4 `options`, `correctIndex` והסבר).

עולם מסופוטמיה כולל 3 משימות לדוגמה כדי להדגים את הזרימה המלאה של המשחק. שאר העולמות מוגדרים עם `missions: []` וממתינים לתוכן.
